# Security Policy

## Supported versions

Security fixes are provided for the latest released version of TaskRuntime.

## Reporting a vulnerability

Do not open a public issue for an undisclosed vulnerability.

Use GitHub's private security advisory feature for this repository. Include:

- the affected TaskRuntime version
- the impact
- a minimal reproduction
- any known workarounds
- whether the issue depends on specific Polytoria behavior

Reports will be reviewed before public disclosure. A fix, advisory, and version update will be coordinated when the report is confirmed.
